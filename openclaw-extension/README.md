# OpenClaw AI Debate Extension

Integrates the AI Debate Simulator with OpenClaw.

## Installation

1. Copy this directory into your OpenClaw extensions folder.
2. Set `DEBATE_API_URL` environment variable to point to the running AI Debate Simulator API (default: `http://localhost:8003`).

## Usage

```
/debate start --topic "Should AI be regulated?"
/debate status
/debate result
```
